# Eyüp Akdeniz — About me

A responsive React portfolio based on eyup_akdeniz_resume_1753.pdf. Built with React, TypeScript, and Vinext/Vite.

## Run locally

Requires Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:5173.

## Build

```sh
npm run build
```

## Edit

- app/page.tsx: biography, work experience, skills, and links.
- app/globals.css: theme and responsive layout.
- public/eyup-akdeniz-resume.pdf: downloadable CV.

The résumé is the source of factual content. No invented projects, testimonials, or availability claims are included.
